# GitHub Projects Data Analysis

This project involves data collection, cleaning, and analysis of GitHub repositories using Python and SQLite.

## Project Tasks:
- **Task 1**: Fetching and cleaning data from GitHub API.
- **Task 2**: Analyzing data using SQL and visualizing trends with Matplotlib.

## Ethics Reflection:
1. **Why is it important to verify data collected from public APIs?**
   Verifying public API data ensures accuracy, completeness, and reliability. Public APIs can contain missing fields, outdated values, or rate-limit gaps, so checking the data prevents incorrect conclusions.

2. **Why should data analysts document the source of their data?**
   Documenting data sources promotes transparency, reproducibility, and ethical data handling. It allows others to verify the findings and traces the data back to its origin.

3. **How can missing or inaccurate data affect data analysis and decision-making?**
   Missing or inaccurate data leads to distorted statistical metrics, biased analytical models, and flawed business decisions, which can result in poor outcomes.
